# Example output (offline test mode)

**These are not agent output.** They were drafted by the deterministic offline-test-mode template used for CI, and show the structure, the gate, the audit trail and the review view. Scored agent runs are added when the demo run happens in a Claude Code session.

Generated by `python3 -m agent.run_playbook` on the committed fixtures with no API key. Every company and person is fictional. Absolute paths were replaced with `$WIRE_OUT_DIR`.

| File | What it shows |
|---|---|
| [`20260924T154159Z-a70fdb/review.html`](20260924T154159Z-a70fdb/review.html) | The one-page review view the run generated: briefs, approval requests, eval score, held, dropped and watched accounts with reasons, the audit trail. Each section links to its source file. Download and open it locally; GitHub shows HTML as source. |
| `20260924T154159Z-a70fdb/briefs/` | The Canadian bank (hs-1001): what changed, what is certain (OSFI E-23, B-13), what depends on structure (every line "Confirm"), next step. The US bank (hs-1002): same structure. |
| `20260924T154159Z-a70fdb/approvals/` | The requests routed to the named account owner: `status: pending`, `send: false`. |
| `20260924T154159Z-a70fdb/audit.jsonl` | Every R-17 record this run wrote, in order. |
| `20260924T154159Z-a70fdb/summary.json` | Every account's outcome and reason, the watch list, each playbook's status and metrics. |
| `20260924T154159Z-a70fdb/scores.json` | The run scored by `python3 -m evals.score_run` (22/22), labelled offline test mode. |

The Markdown and JSON files are the source of truth; the HTML view is generated from them.
